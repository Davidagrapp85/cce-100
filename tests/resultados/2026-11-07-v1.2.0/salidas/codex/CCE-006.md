Esta función calcula un **puntaje a partir de las señales disponibles**. Empieza en 100 y resta puntos por señales de alerta. Un puntaje más bajo indica mayor riesgo.

El cálculo sigue estas reglas:

1. Descarta las señales con nivel `"none"` y las marcadas como ficticias.
2. Si quedan menos señales que el mínimo configurado, devuelve `null`: **no hay suficientes datos para calcular el puntaje**.
3. Resta la penalización configurada por cada señal roja y por cada señal ámbar. Los demás niveles cuentan para el mínimo, pero no restan puntos.
4. Devuelve el resultado sin permitir que sea menor que 0.

Por ejemplo, si una señal roja resta 30 puntos y una ámbar resta 10, dos rojas y una ámbar producen **30 puntos**, siempre que se cumpla el mínimo de señales.

Para producto, conviene distinguir **`null` (datos insuficientes)** de **0 (las penalizaciones suman 100 o más)**. Aunque se llama `getRiskScore`, un valor alto representa menos riesgo según estas reglas.
